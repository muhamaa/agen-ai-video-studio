# AGEN AI VIDEO STUDIO PRO — Online Edition

Website Flask responsif yang disiapkan untuk deployment online dengan Docker/Render.

Fitur MVP: generator naskah dan storyboard (OpenAI bila API key tersedia), gambar adegan, voice-over Edge TTS, subtitle SRT, dan render MP4 menggunakan FFmpeg.

Lihat `DEPLOY-ONLINE.md` untuk panduan publikasi.
